SPELLING BEE 2027 — iPhone flashcard app

INCLUDED
- 500 study words from the supplied 2027 Bulgarian National English Spelling Bee School Level PDF
- Bulgarian prompt, English spelling word, original example sentence
- Mark words as known / practise again; progress saved locally
- Shuffle, search, word list, British English pronunciation, offline cache

INSTALL ON IPHONE (no App Store)
1. Upload the contents of this folder to any HTTPS static website host (for example GitHub Pages, Netlify, or Cloudflare Pages). Keep the folder structure intact.
2. Open the HTTPS website in Safari on the iPhone.
3. Tap Share → Add to Home Screen → Add.
4. Launch Spelling Bee from the new Home Screen icon. After the first load, the app and word list are cached for offline use.

IMPORTANT
A PWA must be served from an HTTPS website to be installable on iPhone. This ZIP is the complete app source/site bundle; it is not a signed native .ipa. No App Store account or publication is required.

DATA
The word list is extracted from the user-provided 2027-Spelling-Bee-study-word-list.pdf. Wrapped example sentences are joined back together.
